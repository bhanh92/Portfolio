# 🌸 Bùi Hoài Anh - Front-End Developer Portfolio

Chào mừng bạn đến với kho lưu trữ mã nguồn trang Portfolio cá nhân của **Bùi Hoài Anh**! Đây là một trang web giới thiệu bản thân hiện đại, trẻ trung và tràn đầy năng lượng, được thiết kế theo phong cách Light Mode (Hồng phấn dễ thương) dành riêng cho các bạn học ngành Công nghệ thông tin muốn thể hiện cá tính riêng.

✨ **Xem trực tuyến tại:** [Vercel Live Demo](https://myyhonah.vercel.app)

---

## 🎨 Điểm Nổi Bật Về Thiết Kế & Tính Năng

*   **Aesthetic & Cute Light Mode:** Giao diện màu hồng ngọt ngào, tươi sáng kết hợp hiệu ứng đổ bóng mượt mà (Glassmorphism), mang lại trải nghiệm thị giác mới lạ và dễ thương.
*   **Hiệu ứng độc đáo:**
    *   **Interactive Background:** Hệ thống hạt lấp lánh (Particles) bay nhẹ nhàng ở nền.
    *   **Cursor Glow:** Vùng sáng nhẹ di chuyển mượt mà theo con trỏ chuột của người dùng.
    *   **Smooth Scroll Animations:** Sử dụng Intersection Observer API cho hiệu ứng xuất hiện (Scroll Reveal) mượt mà khi cuộn trang.
    *   **Typing Effect:** Hiệu ứng gõ chữ năng động ở phần giới thiệu đầu trang.
*   **Đầy đủ các phần chuyên nghiệp:**
    *   **Hero (Giới thiệu đầu):** Điểm nhấn thương hiệu cá nhân cực mạnh với tên viết nghệ thuật (font cursive) nổi bật.
    *   **About Me (Về tôi):** Thẻ thông tin trực quan về định hướng và sở thích.
    *   **Skills (Kỹ năng):** Trình bày kỹ năng chuyên môn trực quan bằng các icon tương ứng.
    *   **Experience & Projects (Kinh nghiệm & Dự án):** Trình bày các dự án thực tế đã hoàn thành theo nhóm 3 người.
    *   **Education (Học vấn & Chứng chỉ):** Tiến trình học tập tại chuyên ngành **CNTT Việt Nhật** và chứng chỉ tiếng Nhật **JLPT N3**.
    *   **Contact (Liên hệ & Footer):** Biểu mẫu liên hệ tích hợp và thông tin mạng xã hội.

## 💻 Công Nghệ Sử Dụng

*   **Core:** React (v18+) + Vite (Trình đóng gói cực nhanh)
*   **Ngôn ngữ chính:** JavaScript (ES6+)
*   **Styling:** Vanilla CSS (Tối ưu hóa hiệu năng, tùy biến giao diện linh hoạt 100%)
*   **Icons:** `react-icons`

## 🚀 Hướng Dẫn Chạy Dưới Local (Máy Tính Cá Nhân)

Để cài đặt và chạy thử dự án này dưới máy tính cá nhân của bạn, hãy làm theo các bước sau:

1.  **Clone (Tải) mã nguồn về máy:**
    ```bash
    git clone https://github.com/bhanh92/Portfolio.git
    cd Portfolio
    ```

2.  **Cài đặt các thư viện phụ thuộc:**
    ```bash
    npm install
    ```

3.  **Khởi động môi trường phát triển (Development Server):**
    ```bash
    npm run dev
    ```
    *Mở trình duyệt truy cập vào đường dẫn `http://localhost:5173` để xem kết quả.*

4.  **Tạo bản build tối ưu hóa cho Production:**
    ```bash
    npm run build
    ```

## 🌐 Hướng Dẫn Deploy Lên Vercel

Dự án này đã được tối ưu hóa hoàn hảo để deploy một chạm lên Vercel:

1.  Đăng nhập vào [Vercel](https://vercel.com) bằng tài khoản **GitHub**.
2.  Chọn **Add New** -> **Project** -> Chọn repository `Portfolio` của bạn.
3.  Nhấp vào **Deploy**. Vercel sẽ tự động phát hiện cấu hình Vite và chạy trang web của bạn chỉ trong 1 phút!
